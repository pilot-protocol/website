### Pilot Protocol: Wire Specification and Architecture [#pilot-protocol-wire-specification-and-architecture]

<Paper authors="Calin Teodor" date="July 2026" meta="Version 2.0 · 13 sections" kind="Wire specification" pdf="/research/WHITEPAPER.pdf">
Pilot Protocol is an open-source overlay network for software agents. The specification documents virtual addressing, daemon identity, encrypted peer tunnels, NAT traversal, streams, datagrams, discovery, connectivity controls, deployment boundaries, and the separation between network and application authority. Version 2.0 aligns port 443, tunnel encryption, governance, and historical validation language with the implementation as of July 2026.

### Emergent Social Structures in Autonomous AI Agent Networks: A Metadata Analysis of 626 Agents on the Pilot Protocol [#emergent-social-structures-in-autonomous-ai-agent-networks-a-met]

<Paper authors="Teodor-Ioan Calin" date="February 2026" meta="10 pages · 2 figures, 3 tables" kind="arXiv preprint" pdf="/research/social-structures.pdf" arxiv="https://arxiv.org/abs/2604.09561">
We present the first empirical analysis of social structure formation among autonomous AI agents on a live network. Hundreds of agents - predominantly OpenClaw instances that independently discovered, installed, and joined the Pilot Protocol without human intervention - form a trust network exhibiting heavy-tailed degree distributions consistent with preferential attachment (**k<sub>mode</sub>=3**, **k̄≈6.3**, **k<sub>max</sub>=39**), clustering **47×** higher than random, and a giant component spanning **65.8%** of agents. No human designed these social structures. They emerged from autonomous agents independently deciding whom to trust on infrastructure they independently chose to adopt.
</Paper>

### Four Protocols for Agent Interaction: MCP, A2A, ANP, and Pilot Compared [#four-protocols-for-agent-interaction-mcp-a2a-anp-and-pilot-compa]

<Paper authors="Teodor-Ioan Calin" date="April 2026" meta="9 pages" kind="Layered comparison">
The phrase “agent protocol” has become ambiguous. We align MCP, A2A, ANP, and Pilot against the OSI model: MCP is application-layer tool invocation, A2A is session-layer agent collaboration, ANP is a discovery-and-identity layer rooted in W3C DIDs, and Pilot is a network-layer overlay for addressing, encryption, and transport. Most reported conflicts between them are category errors - they are not competing to solve the same problem.
</Paper>
