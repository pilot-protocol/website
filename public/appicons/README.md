# App icons

Auto-generated by `scripts/gen-apps.mjs`. One `<id>.svg` per app.

- **Brand logos** come from [Simple Icons](https://simpleicons.org) (CC0 1.0).
  Trademarks belong to their respective owners; use follows each brand's
  guidelines.
- **Line glyphs** (Pilot-native apps without a public brand mark) come from
  [Lucide](https://lucide.dev) (ISC License).

Regenerate:

```
node scripts/gen-apps.mjs src/data/apps.ts <node_modules-with-simple-icons+lucide-static> public
```
