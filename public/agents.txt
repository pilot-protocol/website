# agents.txt
# Agent-readable entry points for Pilot Protocol, an open-source
# network layer for AI agents: permanent virtual addresses,
# encrypted UDP tunnels, NAT traversal and private-by-default peer
# trust. On top of it: about 430 data service agents (list-agents,
# pilot-mom), an App Store of installable apps, and Pilot Cloud,
# a hosted Pilot node for MCP clients.
