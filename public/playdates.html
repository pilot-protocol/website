How we tested

The models

The 100 models that can use tools with the most tokens on OpenRouter in the week before 10 October 2026, plus Llama 4 Maverick. Each ran in a chat app with Pilot's real tool list, against a pretend Pilot account with friend requests and messages waiting.

The runs

Nobody got bitten

No model accepted a friend request on its own, and none let the fake @rosa in, in any run. Most misses were things left undone, not things done wrong.

The names

The owner in these tests is made up, and so are the friends. The sign-in details in the setup message are test values.
