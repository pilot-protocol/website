# Claim audit: src/pages/docs/consent.astro
Audited: 2026-07-10 · Sentences examined: 170 · verified: 74 · false: 33 · unverifiable: 6 · opinion: 54 · example: 3

This page has severe drift from source. The three headline problems: (1) the review prompts it describes are dormant behind feature flags that default OFF; (2) the broadcasts consent flag gates *sending*, not receiving — the entire "incoming datagrams dropped" opt-out story is wrong; (3) several skill-injection and sandbox guarantees ("status is a preview", "set-mode disabled removes files", "unset paths are redirected", "confined process cannot write agent configs") are contradicted by the code.
